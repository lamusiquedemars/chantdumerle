# Le Chant du Merle — propositions de sélections et jeux composés
Document de travail V1. Les propositions utilisent les modèles présents dans le CSV Woo fourni. Les jeux composés doivent être validés musicalement avant publication.
## Légende
- `jeu complet` : jeu fabricant ou jeu uniforme, vendable tel quel si le SKU de jeu existe, sinon recomposable par cordes.
- `jeu composé` : combinaison éditoriale de cordes de marques/modèles différents.
- `confiance` : niveau de confiance musical/commercial de la proposition, pas une vérité acoustique absolue.


## Structure de travail Woo

Chaque ligne ci-dessous représente un produit Woo vendable. Pour les jeux composés, les colonnes de cordes doivent pointer vers les produits cordes exacts du catalogue Woo, idéalement par SKU. Les propriétés techniques détaillées (âme, filage, matière, tension, attache, taille, EAN, etc.) restent portées par ces produits cordes, pas recopiées ici.

Colonnes à compléter avant import/publication :

| Colonne | Rôle |
|---|---|
| Code | Identifiant éditorial stable du jeu, ex. VLN-18. |
| SKU jeu Woo | SKU du produit vendable composé, ex. CDM-SET-VLN-18. |
| Titre produit | Nom affiché sur la fiche produit et les listes. |
| Type produit | `jeu complet` ou `jeu composé`, à mapper vers `pa_type_produit`. |
| Profil sonore | Repère client : chaud, équilibré, brillant. |
| Usage | Repère client : étudiant, orchestre, soliste, etc. |
| Description courte | Vraie accroche produit, visible en haut de fiche et sur carte. |
| Description longue | Texte éditorial complet : intention sonore, public visé, cas d’usage, limites éventuelles. |
| Composition affichée | Version lisible client, générée ou rédigée depuis les produits cordes exacts. |
| Cordes du jeu | Une colonne par corde. Valeur attendue : SKU corde Woo + nom produit exact. |
| Note interne | Commentaire de validation, non nécessairement affiché. |

Règle importante : ne jamais écrire seulement “Sol Evah Pirazzi” si plusieurs Sol existent. La cellule doit identifier le produit corde Woo exact ; le front pourra ensuite afficher ses propriétés depuis Woo.
